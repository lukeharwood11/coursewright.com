# AGENTS — `src/quizzes/quiz-edit/`

Staff editor for quiz questions (main column) plus a side panel for possible points, **Accept entries** (optional start/end), attempts, **Show results immediately**, and answer-key sharing. The title lives in the header and saves when the field loses focus. Header actions match resource edit: quiet **Add/Edit description**, **Save** / desktop **Save & close** / **Cancel** (reads **Close** when unchanged); below `md`, those collapse into a **⋯** menu.
