# AGENTS — `src/materials/model/`

Pure material rules: kinds, visibility, block body shapes, playback, paths, validation, **quiz** payload, page-editor helpers (table size, slash-command matching, clipboard image extraction), **version snapshot** preview parsing. Rich text is Lexical JSON in `body.lexical` (legacy `markdown` still reads). Video blocks are URL embeds. **Quizzes** are Lexical `quiz` nodes inside that JSON (correct answers on the node), not a new material kind. In-page files stay inside the Lexical JSON (`file` nodes), not a new block kind. `playback.ts` picks audio/video/pdf/image from MIME with filename-extension fallback for vague MIME.
