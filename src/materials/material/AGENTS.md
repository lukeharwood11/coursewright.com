# AGENTS — `src/materials/material/`

View and edit a material (page / link / file). Page content uses the Lexical editor with a playground-style icon toolbar, slash commands (`/`), and insert popups (table size, link, video). Paste image uploads as an in-page file and renders as a clean picture (no filename chrome; Remove on hover while editing). Save lives in the header and writes a version only when something changed. Print and Share stay visible. Parents see quiz questions only; staff see the answer key. Audio file attachments (file materials and in-page files) use the shared `AudioPlayer` (play/pause, scrub, time, 1×/1.5×). When adding or replacing a **file** material, instructors can **record a clip** (under 5 minutes) with the device microphone and upload it as that file.
