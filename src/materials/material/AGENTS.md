# AGENTS — `src/materials/material/`

View and edit a material (page / link / file). Edit chrome matches resource + quiz edit: compact header (back, inline title saved on blur / Enter / leave, description dialog, **Save** / **Cancel**/**Close**, desktop **Save & close**; mobile **⋯** menu), Lexical page editor filling most of the viewport with **Version history** in the editor toolbar (⋯ on small screens; header for link/file), then dates and submission settings. Paste image uploads as an in-page file and renders as a clean picture (no filename chrome; Remove on hover while editing). Save writes a version only when something changed. Print and Share stay visible on the view. Parents see quiz questions only; staff see the answer key. Audio file attachments (file materials and in-page files) use the shared `AudioPlayer` (play/pause, scrub, time, 1×/1.5×). Page **Audio** insert reuses `AudioSnippetRecorder` in a popup, then uploads as an in-page `file` node. When adding or replacing a **file** material, instructors can **record a clip** (under 5 minutes) with the device microphone and upload it as that file.
