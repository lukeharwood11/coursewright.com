# AGENTS — `src/lesson-plans/lesson-plan-edit/`

Create and edit a lesson plan (title, week, week note, per-day notes and materials). Staff Teacher view only. Week form uses wrapping day cards. **Days to show** segmented control (School days / Home days / Weekdays) filters visible cards without clearing notes or materials; choice is remembered per course in `localStorage`. Default visible days follow the selected preset (org school days, org home days, or Mon–Fri). An **Add another day** button opens a modal of remaining weekdays. Each day uses **Link content** to open one popup that switches between an outline-style material multi-select and Resources the course already links (not the whole library).
