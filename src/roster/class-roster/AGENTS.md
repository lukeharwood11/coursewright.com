# AGENTS — `src/roster/class-roster/`

Org-scoped **class** (student group). Not a course — no units or materials.

List-first members; **Add students** opens batch multi-select or batch create-and-add. Removing a member does not change course enrollments.

Owners and admins assign optional **teachers** (class leads: owner / admin / instructor, including people who have not claimed) as compact cards. **Add teacher** opens a search modal. Instructors see the list. Names come from `org_profiles`. Leads are notified in Activity when someone posts in a discussion for this class, after they have claimed.
