# AGENTS — `src/print/`

One-tap print: material, unit, this week. Browser print / system share sheet.

## Scope

- Print-friendly routes/layouts (no app chrome)
- **Print**, **Print unit**, **Print this week**
- White page, black text, no beige `--paper` fill when printing

## Rules

- Super easy — one step after click; no export wizard / format picker.
- Create → print works with **empty roster**.
- Whole-course print is **out of scope** for initial release.
- Follow [STYLE_GUIDE.md](../../docs/STYLE_GUIDE.md) Print section.

## Don’t

- Call it Export / Generate PDF as the primary action.
- Print decorative fills that waste ink.
- Require students or parent invites before print works.
