# AGENTS — `src/print/model/`

Pure print rules: packet shape, this-week order (per student, no mashed shared-material headers), filenames, QR/image data URLs, PDF concat. `includeAnswerKey` is staff-only for page quizzes. This-week print uses the **full** dated week (due and assigned) **plus published lesson plans** (per student, lesson plans first). No React document tree here — that lives under `print/print/`.
