# AGENTS — `src/resources/resource-edit/`

Word-like resource editor. One compact header row: back, editable title, quiet **Add/Edit description**, **Save** / desktop **Save & close** / **Cancel** (reads **Close** when unchanged). Below `md`, those actions live in a **⋯** menu. Document body uses the Lexical editor and fills most of the viewport. Link URL stays a slim field under the header; file rename is title-only.
