# AGENTS — `src/styles/`

Global CSS: Tailwind entry + STYLE_GUIDE CSS variables.

## Scope

- `index.css` tokens (`--green`, `--paper`, fonts, radii)
- Global base styles

## Rules

- Tokens match [STYLE_GUIDE.md](../../docs/STYLE_GUIDE.md).
- Print overrides belong primarily in `print/` (white background, hide chrome).

## Don’t

- Encode domain layout here that belongs in domain components.
