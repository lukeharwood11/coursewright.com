# AGENTS — `src/notifications/databridge/`

PostgREST for `notifications` (own rows only) and this person’s `push_subscriptions`. Mark read with an update on `read_at`. Opening a discussion acks `discussion_message` rows only — `@mention` rows stay until the person clicks Activity or opens that row from a device notification. Opening an announcement acks `announcement` rows. A push tap with `?activity=` acks that one row. Realtime `postgres_changes` channels live here; page hooks (and org chrome) subscribe and invalidate TanStack Query. Never insert notification rows from the app. The public VAPID key comes from `web-push-public-key`.
