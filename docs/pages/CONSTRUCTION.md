# CONSTRUCTION

**URL:** `/contact`, `/privacy`, `/terms`, `/cookies`  
**URL map:** [URLS.md](../URLS.md)

## Audience

Anyone following a footer legal or contact link before that page has real copy.

## Purpose

Honest placeholder for public pages that normally exist in a site footer but are not written yet — without inventing legal or contact text.

## Behavior

- Public, unauthenticated.
- One screen is reused for every unfinished footer URL.
- Heading names the page the visitor asked for (Contact us, Privacy, Terms of use, Cookie policy).
- Lists every link that appears in the marketing footer so visitors can reach ready pages or the other placeholders.
- No forms, no invented policy body, no fake contact address.

## Data shown

- “In construction” status
- Name of the requested page
- Static footer link list (product, account, legal) — same destinations as the site footer
- Current path is marked in the list, not linked to itself

## Contents

- Status + short explanation
- Footer page list grouped like the footer (Product, Account, Legal)
- Shared marketing chrome (header / footer)

## Primary actions

- Go to a ready page (home, about, pricing, sign in, sign up)
- Try another footer placeholder
