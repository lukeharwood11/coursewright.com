# FILL_CYCLES

**URL:** `/my/<org-slug>/fill-cycles`  
**URL map:** [URLS.md](../URLS.md)

## Audience

Staff. Owners and admins create cycles. Other staff can open the list and a cycle they can see.

## Purpose

Create and review marking-period work bundles. A cycle asks for grades, attendance, and outcomes packages. It does not assemble or send a report card.


## Behavior

- Lists every cycle for the organization, open and closed, with the due date.
- Owners and admins create a cycle: name (80 characters), due date, audience, and which packages are required.
- Audience is the whole organization, selected classes, or selected courses.
- A class audience includes class attendance and the courses current members of those classes are taking.
- A course audience includes those courses only. Class attendance is not part of it.
- An organization audience includes active courses and class attendance.
- Outcomes are required only for courses that have at least one outcome that is not archived.
- Period feedback is a comment package. It can be turned off. It defaults on.
- The due date is soft. Past due does not lock edits.
- Empty list says there are no fill cycles yet.

## Data shown

- Cycle name, due date, open or closed
- Create form: name, date, audience, class or course picks, package toggles

## Contents

- Cycle list
- New fill cycle form (owners and admins)

## Primary actions

- Open a cycle
- Create a fill cycle
